# 📖 EBD Gestão

Sistema de gestão para Escola Bíblica Dominical (EBD), desenvolvido com foco em simplicidade, organização e usabilidade para pastores e secretários.

---

## Sobre o projeto

O **EBD Gestão** tem como objetivo substituir controles manuais (papel e caneta) por uma solução digital simples, eficiente e acessível.

A proposta é oferecer uma interface intuitiva para facilitar o dia a dia da administração da EBD.

---

## Tecnologias utilizadas

Este projeto foi desenvolvido com:

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- TanStack React Query

---

## Funcionalidades atuais

- Dashboard inicial
- Cadastro de alunos
- Cadastro de professores
- Organização por turmas
- Calendário (estrutura inicial)
- Recados (estrutura inicial)
- Módulo financeiro (em desenvolvimento)

